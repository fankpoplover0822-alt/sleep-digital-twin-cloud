# Third-party model notice

## SleepFM clinical

This project includes the official research code and released checkpoints from
`zou-group/sleepfm-clinical` at commit `2bcbae04c3592f61352addb7ac3d4193f0a3ca25`.

- Project: https://github.com/zou-group/sleepfm-clinical
- Paper: https://doi.org/10.1038/s41591-025-04133-4
- License: Creative Commons Attribution-NonCommercial 4.0 International

SleepFM output in this application is research-only. It is presented as a CoxPH
relative hazard ranking, not a diagnosis, calibrated probability, prescription,
or autonomous clinical recommendation. Commercial or production hospital use
requires a separate licensing and clinical-governance review.
